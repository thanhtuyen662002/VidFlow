# M7.1 timeline snapshots

Migration 14 adds `timeline` (project, timestamp, revision, status),
`timeline_track` (video/dialogue/music/subtitle, order, muted),
`timeline_clip` (scene/take/asset and original path, source in/out, timeline
start, duration, order), and `timeline_subtitle` (scene, text, start/end,
order). All time values are seconds, as in M6. No ratio, resolution, crop or
LUT is stored. Each build allocates the next project revision, inside one
immediate transaction, after validating all scenes. Media is never written.
Source foreign keys restrict deletion rather than silently removing snapshot
clips when a source is deleted.

APIs in `src/edit/timeline.ts`:

- `buildTimelineFromSelectedTakes(db: DatabaseSync, projectId: string): Timeline`
- `getTimeline(db: DatabaseSync, id: string): Timeline | undefined`

Returned tracks, clips and subtitle cues are ordered. Missing selections throw
`NoSelectedTakeError` (`TIMELINE_SCENE_NO_SELECTED_TAKE`); invalid choices or
intervals throw `InvalidTimelineSelectionError` (`TIMELINE_INVALID_SELECTION`).
Both include `sceneIds`. Path containment uses the existing media path validator.

Integration details and differences from the planning documents:

- The supplied M7.md has no separate M7.1 section, detailed data rules or
  version policy. This task defines append-only snapshots.
- M7 mentions crop/LUT alongside selections; this task keeps these out of the
  ratio-independent timeline, for later export tasks.
- M6 production choices live in the lazily created `render_reviews` table,
  separately from repository `selections`. Use the latest review for each
  scene, merging owner fields through M6's `resolveSelection`. A review with
  no choice fails rather than falling back to a stale selection. Scenes with
  no review use their current repository selection. Scene order matches M6
  planning (`index`, then ID), including script-variant scenes.
- Dialogue clips reference the take's audio when scene dialogue/SFX or
  `metadata.hasAudio` indicates audio. The dialogue track starts muted per
  M7's default Veo mute policy; later dubbing can replace these references.
  Subtitle text covers the scene's selected interval on the timeline; no
  word-level alignment is available yet.
- Existing project/scene models have no assigned music source or interval.
  The music track is empty until music assignment is implemented. Assets in
  the library alone do not imply a soundtrack selection.
- A repository take duration of zero is the legacy unknown-duration default;
  positive known durations bound out points. M6 review resolution retains its
  existing stricter duration validation.
