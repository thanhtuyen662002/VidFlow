# M8.2: Electron và IPC

`src/app/main.ts` xuất `startElectron(services, rendererUrl)` cho composition root:
truyền cùng instance `createCoreService` dùng cho MCP và URL của UI M8.3.
Không tạo UI hay giả lập dependency sản xuất trong mốc này. Main tải Electron
động nên các kiểm thử cấu hình cửa sổ chạy bằng Node, không mở cửa sổ.

Giữ nguyên package.json/package-lock.json theo AGENTS.md. Electron đã có sẵn;
chưa thêm script khởi động hay trường main vì quy tắc cấm sửa hai file này.
Entry tích hợp ứng dụng cần gọi `startElectron` sau khi tạo các dependency thật.
Preload là CommonJS độc lập để chạy trong sandbox mà không cần import module
cục bộ hoặc hỗ trợ TypeScript trong preload.

IPC lấy schema trực tiếp từ `services.listCommands()`, đổi dấu chấm thành dấu
hai chấm; validate trước `services.execute()`. Test đối chiếu toàn bộ API preload
với registry để phát hiện thiếu hoặc thừa lệnh khi service thay đổi.

Nguồn tiến độ ở service bọc Flow driver của M6 và phát trạng thái running,
completed, failed hoặc needs_owner cho từng job. Chưa có phần trăm trung gian
từ M6 nên không tự tính phần trăm. Mỗi cửa sổ có subscription riêng, hủy khi
đóng; forwarder chỉ gửi trường cho phép và thông báo trạng thái cố định.
Lỗi dependency không gửi stack hoặc thông báo tùy ý đến renderer.
