# M9.2 — Mẫu series

API tại `src/repo/templates.ts` theo quy ước repository hiện có:

- `saveProjectAsTemplate(db, projectId, { name })`
- `createProjectFromTemplate(db, templateId, { name })`
- `listTemplates()`, `getTemplate(templateId)`, `deleteTemplate(templateId)`

Registry dịch vụ cung cấp `template.save`, `template.createProject`, `template.list`, `template.get`, `template.delete`. IPC và MCP tự lấy registry này; preload và kiểu API cũng được cập nhật. Chưa làm UI: workspace không có thư mục renderer để tích hợp.

Mẫu nằm tại `<dataDirectory()>/templates/<UUID>/template.json` và `images/`. JSON ghi qua file `.partial` rồi rename. UUID được sinh nội bộ cho cả mẫu lẫn ảnh. Mẫu không giữ ID Bible/reference cũ: chỉ giữ nội dung, tên handle, role, description, priority và danh sách ảnh tương đối. Dự án mới dùng API `createProject`, `setBible`, `createReference` để tạo ID mới; ảnh được `copyFileSync` vào `refs/`.

Whitelist config chỉ có `aspect`: đây là trường cấu hình tái dùng hiện có trong Project. Không sao chép budget/credit, status, tài khoản, hàng đợi, take, output hay lịch sử. Phong cách hiện nằm trong Bible.style; mẫu lưu thêm trường style tương ứng. Không có kho cấu hình phong cách riêng trong code hiện có. Bible có thể null nếu dự án nguồn chưa tạo Bible.

Tái sử dụng `resolveInside` và `assertInsideDataDir`: kiểm tra containment cả đường dẫn resolve và realpath của tổ tiên, có xử lý Windows và symlink. Kiểm tra magic PNG/JPEG/WEBP khi lưu và khi tạo dự án. Lỗi sao chép xóa mẫu chưa hoàn tất; lỗi tạo nội dung dự án xóa bản ghi và thư mục dự án mới. Không thay đổi M9.1 hoặc triển khai M9.3 (workspace chưa có module archive).

## Kiểm chứng

Node v24.19.0. Không có script lint/typecheck trong package.json; không sửa dependency.

Lệnh chạy:

```
npm test
node --test --test-isolation=none
node --test --test-isolation=none test/service.test.ts test/templates.test.ts test/electron-ipc.test.ts test/analytics-bridges.test.ts test/mcp-flow.test.ts
```

Kết quả thực tế của lệnh cuối:

```
ℹ tests 16
ℹ suites 0
ℹ pass 16
ℹ fail 0
ℹ cancelled 0
ℹ skipped 0
ℹ todo 0
ℹ duration_ms 6109.1439
```

Test mẫu bao gồm Bible, hai ảnh PNG thật, handle và compiler trỏ tới ảnh mới, whitelist, hash JSON/ảnh trước và sau sửa Bible/metadata/ghi đè/xóa ảnh mới, traversal/absolute path bên ngoài, ảnh thiếu/sai magic, list/get/delete. Các test workflow service/MCP gọi đủ năm lệnh mới. Chỉ cập nhật kỳ vọng registry trong test analytics, không đổi logic analytics.

`npm test` không chạy được file test vì sandbox chặn spawn (`EPERM`). Chạy toàn suite không isolation cũng bị hook dùng thư mục tạm bên ngoài workspace. Đã chạy tiếp từng file `*.test.ts` qua PowerShell, đặt TEMP/TMP bằng workspace, với `node --test --test-isolation=none <file>`; sau đó sửa coverage workflow service cho năm lệnh mới và chạy lại nhóm 16 test ở trên.

Các lỗi ngoài phạm vi còn quan sát được khi chạy từng file: packaging thiếu config/electron-builder.yml và config/vite.main.config.ts; script-variants/script-gate thiếu prompts/script-writer.system.md; flow/selftest thiếu config/flow-selectors.json; renderer/workflow-client thiếu renderer/src/workflow.ts; renderer/app thiếu package react; redaction thiếu .gitignore. CLI project/reference bị spawnSync EPERM; LLM báo LLM_SPAWN; media test fake executable và script-cli thất bại ở assertion liên quan gọi tiến trình. Không có ffmpeg/ffprobe nên các kiểm thử media tương ứng được skip. Không tuyên bố toàn suite đã qua; các module ngoài task không được sửa để xử lý các lỗi này.
