# M10.5: derived motion media paths

Motion's extracted frames, logo crops, source clips and comparison previews live
under the absolute project path `frames/motion/derived/`. The directory is created
before ffmpeg writes; unique filenames avoid overwriting existing outputs.
This follows the shared media runner's existing output policy without changing
`src/media/paths.ts` or its errors. Inputs under project `renders/` are already
accepted by the runner's data-directory validation.

Raw clips and images downloaded from Flow remain under `renders/motion/`.
The coordinator validates downloaded and derived files against their respective
roots. Existing database checkpoints persist the new derived paths, including
the cropped chain frame path and SHA-256; resume reuses those checkpoints.
The crop operation and AI declaration are unchanged: only the Flow logo band is
cropped, with retained AI watermark pixels copied unchanged.
