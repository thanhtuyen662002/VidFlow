# M10.6: source-timed assembly

The public API is `reviewMotion` / `assembleMotion` in `src/motion/assemble.ts`.
`selectVariant` remains the owner selection API. It now records `ownerVariantId`,
including when the owner chooses the existing automatic selection. Older automatic
selections are not treated as owner overrides.

M4's existing injected `LlmClient` is reused without changes. The structured review
request includes original/generated frame comparisons, the preset and segment.
Strict JSON parsing rejects invalid scores, unknown properties and nonboolean face
flags. Invalid reviews are checkpointed, never used as automatic fallbacks.
The owner can resolve a failed review through `selectVariant`.

M7's export module adds video-only stretching, joining through the shared
`concatSegments` implementation, original-source audio muxing, and disclosure
sidecars. Its existing publish-package disclosure format is shared through
`aiDisclosure`; the existing Vietnamese statement is preserved. No crop, blur or
watermark-removal filter is introduced. Source audio is mapped once at its original
timestamps, with no scene-by-scene trimming or audio stretching.

Reviews, owner selection, stretched files and joined/muxed/exported checkpoints
remain in `render_jobs.motion_state`. Assembly never calls Flow. Files are written
to unique temporary paths and renamed when complete. Restart validates file fps
and duration before reusing completed steps. Changed selection, preset or audio
configuration invalidates the relevant checkpoint keys. Exports have unique names
inside the project exports directory. Full UI/CLI/MCP wiring remains M10.7.

Tests use `node --test`, as required by AGENTS.md and M10.md, rather than the
manager's pytest wording. Runtime-generated media is removed with the test home;
no media fixtures or ignore/configuration files are added. This context workspace
contains no .gitignore or package.json; neither is recreated.
